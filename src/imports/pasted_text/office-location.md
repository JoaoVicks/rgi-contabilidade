Implement the Location / Office section immediately after the FAQ section.

Do NOT modify, recreate, or redesign the existing FAQ section.

Do NOT generate any images.

Use the existing map implementation or map asset from the project.

The Figma design is the source of truth.

The objective is to faithfully reproduce the visual composition, spacing, proportions, typography, and interactions shown in the design.

────────────────────────────────────

## 1. SECTION PURPOSE

This section has one primary purpose:

Help visitors understand where RGI's office is located and provide an easy way to get directions.

Keep the section simple.

Do not turn it into a large contact-information section.

The map should be the main visual element.

────────────────────────────────────

## 2. SECTION BACKGROUND

Use the same warm off-white / cream background used throughout the website.

Maintain the existing RGI visual identity.

Do not introduce a new background color.

Keep generous whitespace around the content.

The section should feel calm and spacious.

────────────────────────────────────

## 3. HEADER AREA

At the top of the section, create a horizontal header area.

The main heading should read:

"Visite nosso escritório"

Use the existing burgundy typography.

The heading should be visually prominent but not oversized.

Place the CTA button directly beside the heading on desktop.

────────────────────────────────────

## 4. DIRECTIONS BUTTON

Place the button:

"como chegar"

directly beside the heading.

The button should use the existing RGI burgundy button style.

Include:

• Hover state
• Pressed state
• Keyboard focus state
• Smooth transition

The button should clearly communicate that it opens directions to the office.

Do not create multiple buttons.

────────────────────────────────────

## 5. SUPPORTING TEXT

Below the heading and CTA, display the supporting text:

"Prefere conversar pessoalmente? Nossa equipe está pronta para recebê-lo e ajudar com suas necessidades contábeis."

Keep the paragraph relatively narrow.

Use a smaller, lighter text style than the heading.

Maintain the left alignment shown in the design.

Do not center this paragraph.

────────────────────────────────────

## 6. MAP

The map is the primary visual component of this section.

Position it directly below the introductory content.

The map should:

• Occupy most of the available content width.
• Have a fixed visual height similar to the Figma design.
• Have rounded corners.
• Remain centered within the section.
• Maintain its geographic proportions.
• Clearly communicate the office location.

Do not make the map full-screen.

Do not allow the map to touch the viewport edges.

The map should remain inside the same content width as the section's text.

────────────────────────────────────

## 7. MAP VISUAL STYLE

Preserve the visual appearance shown in the design.

The map should have a light, clean appearance.

Avoid dark map themes.

Avoid excessive map controls.

The map should feel integrated with the website rather than looking like a separate application.

Maintain the rounded corners shown in the Figma design.

────────────────────────────────────

## 8. OFFICE LOCATION

Use the actual RGI office location configured in the project.

The office location should be represented by a clear marker.

Do not invent an address.

Do not invent geographic information.

If the project already contains a map configuration, address, coordinates, or map embed, reuse that information.

────────────────────────────────────

## 9. "COMO CHEGAR" INTERACTION

The "como chegar" button should provide a useful navigation action.

When clicked, open the appropriate map/navigation experience for the configured office location.

Prefer opening the user's map/navigation service rather than creating a custom navigation interface.

The button should work on both desktop and mobile.

Do not create a modal unless it already exists in the design.

────────────────────────────────────

## 10. MAP INTERACTION

The map may remain interactive.

Users should be able to:

• Zoom
• Pan
• Inspect the location

However, map interaction must not interfere with the rest of the page.

Prevent accidental horizontal page scrolling.

Do not allow the map to create horizontal overflow.

────────────────────────────────────

## 11. SCROLL ENTRANCE ANIMATION

When the section enters the viewport:

1. Heading fades in.
2. "como chegar" button appears subtly.
3. Supporting text fades in.
4. Map fades in with a very subtle upward movement.

Keep the animation restrained.

Recommended duration:

200–350ms

Avoid:

• Bounce
• Rotation
• Large scale effects
• Excessive parallax

The map itself should not have a dramatic animation.

────────────────────────────────────

## 12. RESPONSIVE DESIGN

Desktop:

• Heading and button remain on the same horizontal line.
• Supporting text remains below them.
• Map occupies the majority of the content width.
• Maintain the generous whitespace shown in the design.

Tablet:

• Preserve the same structure.
• Reduce horizontal spacing proportionally.
• Keep the heading and button together if space allows.

Mobile:

• Stack the heading and button vertically if necessary.
• Keep both aligned to the left.
• Supporting text remains below.
• Map becomes full-width within the page's horizontal padding.
• Maintain rounded corners.
• Reduce map height appropriately.

Do not allow the map to cause horizontal overflow.

────────────────────────────────────

## 13. SPACING

Preserve the visual rhythm from the Figma design.

There should be:

• Generous spacing above the heading.
• Small spacing between heading and supporting text.
• Comfortable spacing between the text and map.
• Consistent horizontal margins around the map.

Do not compress the section.

Do not add excessive empty space either.

────────────────────────────────────

## 14. ACCESSIBILITY

Ensure:

• The "como chegar" button is keyboard accessible.
• The button has a visible focus state.
• The map has an accessible label describing the office location.
• Interactive map controls remain usable.
• Text maintains sufficient contrast.
• Touch targets are sufficiently large.

Respect prefers-reduced-motion.

────────────────────────────────────

## 15. DESIGN FIDELITY

Do not add:

• Contact forms
• Phone numbers
• Email addresses
• Opening hours
• Social media links
• Additional office information
• Multiple maps
• Extra cards
• Decorative illustrations

unless those elements already exist in the Figma design.

This section is specifically the office-location section.

Keep it focused.
